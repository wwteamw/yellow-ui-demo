# Yellow UI — Interactive Mobile Demo (PWA & Telegram Mini App)

Автономный прототип мобильного приложения с поддержкой **Telegram Mini App** и установки на главный экран **iPhone / Android (PWA)**.

## Как включить ссылку за 30 секунд (1 раз)
1. Откройте в этом репозитории **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите ветку **`main`** и папку **`/ (root)`**, нажмите **Save**.
4. Через ~30–60 секунд приложение будет круглосуточно доступно по адресу:
   `https://wwteamw.github.io/yellow-ui-demo/`

## Подключение к @BotFather
- Откройте `@BotFather` → `/mybots` → выберите бота → **Bot Settings → Configure Mini App** и укажите `https://wwteamw.github.io/yellow-ui-demo/`.
